# SMT Version 6.0

## 🇧🇷
## Recursos
- Monitoramento do Sistema
- Controle de Processos
- Gerenciamento de Usuários
- Informação do Hardware (Novo!)

## Como rodar o .jar do SMT?
1) Ter o Java 17 (ou superior) instalado
2) Baixe o arquivo .jar do SMT
3) Abra o terminal / prompt de comando e vá até a pasta onde o .jar está (Exemplo: cd Downloads)
4) Execute o comando: java -jar SMTv6.jar
